Device configuration for Xiaomi 15 Ultra
=========================================

The Xiaomi 15 Ultra (codenamed _"xuanyuan"_) is a high-end smartphone from Xiaomi.

It was announced on February 2025. Release date was 2 March 2025.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm SM8750-AB Snapdragon 8 Elite (3 nm)
CPU     | Octa-core (2x4.32 GHz Oryon V2 Phoenix L & 6x3.53 GHz Oryon V2 Phoenix M)
GPU     | Adreno 830
Memory  | 12/16 GB RAM
Shipped Android Version | 15.0 with HyperOS 2
Storage | 256/512/1024 GB
Battery | Non-removable Li-Po 5410 mAh battery
Display | 1440 x 3200 pixels, 20:9 ratio, 6.73 inches, LTPO AMOLED, 1B colors, 120Hz, Dolby Vision, HDR10+, 3200 nits (peak)
Camera  | 50MP(Primary) 50MP(Ultra-wide) 200MP(Periscope Telephoto 4.3x Optical Zoom) 50MP(Telephoto 3x Optical Zoom)
